About Mahendra Mali (Max)

Security Researcher, Systems Architect & Software Engineer

Engineering Biography & First-Principles Mindset

I am Mahendra Mali (Max), a systems architect, security researcher, and software engineer based in Gujarat, Bharat (India). Operating with a first-principles engineering philosophy (as a processor, not a hard drive), my focus spans the entire technological continuum from bare metal firmware up to high-concurrency cloud networks.

Over the past 8+ years, I have engineered open-source Linux distributions, on-device AI runtimes, high-speed reverse proxies in Go, cellular modem AT telemetry engines, and resilient embedded microcontroller systems. My engineering discipline unites academic rigor with rapid, production-proven delivery.

Seven Core Engineering Disciplines

1. Circuit Designing & Hardware Engineering

Designing electronic schematics, multi-layer custom PCBs, resonant inductive coupling arrays, and bench testing with precision oscilloscopes and logic analyzers.

2. Embedded Microcontrollers & IoT Firmware

Programming ESP32, ESP8266EX (160 MHz), STM32, and Arduino platforms. Implementing non-volatile EEPROM state recovery engines, 400 kHz fast I2C bus communications, and asynchronous WebSockets/MQTT.

3. Low-Level Linux & Kernel Architecture

Custom kernel driver compilation, OpenWrt 6.18 distribution engineering on Qualcomm IPQ9574 AArch64 hardware, RTL8812AU 802.11ac raw frame injection, systemd daemons, and LuCI web dashboard engineering.

4. Telecom Security & Modem Reverse Engineering

Qualcomm AT baseband protocol diagnostics, 5G NR carrier aggregation locking (n78 + n28 bands), ADB cellular telemetry interfaces, and defensive telecom security audits.

5. High-Performance Web & Distributed Systems

Low-latency Go reverse proxies, modern CSS responsive architectures, real-time bidirectional telemetry streaming, and SQLite/PostgreSQL database optimization.

6. Native Android SDK & Low-Level Internals

Developing native Android tools with Kotlin and Java, LiteRT on-device neural network execution, Android Debug Bridge (ADB) automation, and direct Linux userland manipulation in Termux environments.

7. Enterprise Network Infrastructure & Routing

Enterprise network topology design, TCP/IP socket streams, Wi-Fi 6 channel planning, VLAN segregation, and encrypted V2Ray/Xray edge proxy pipelines.
