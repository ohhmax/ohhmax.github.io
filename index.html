About Me

I am Mahendra Mali (Max), a dedicated security researcher, systems architect, and software engineer based in Gujarat, Bharat (India). My journey is defined by a deep curiosity for computing, from building responsive full-stack platforms and analyzing low-level Android frameworks to programming embedded microcontrollers and securing Linux environments. I combine structured academic discipline with hands-on production engineering to build dependable real-world software.

What sets my engineering approach apart is an end-to-end understanding across software and systems security. Rather than staying confined to a single layer, I design clean database schemas, implement performant APIs, craft intuitive user interfaces, and interface directly with embedded hardware sensors. Whether building the MaxFit fitness application, programming multi-relay controllers with non-volatile power recovery, or streamlining government server administration at Gujarat Sachivalay, I focus on dependable real-world execution.

Every day, I treat systems architecture with discipline: emphasizing maintainable architecture, memory safety, and practical utility. Having completed my Master of Computer Applications (MCA) at Sankalchand Patel University (SPU), I specialize in defensive security research, on-device AI acceleration, and resilient software engineering.
